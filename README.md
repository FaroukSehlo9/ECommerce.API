# E-Commerce API 🛒

An enterprise-level E-Commerce backend built with **.NET 8** following **Clean Architecture** principles. This project is designed to be scalable, maintainable, and highly organized.

---

## 🏗 Architecture Overview
The project follows **Clean Architecture** to ensure separation of concerns and ease of testing. It is divided into 4 main layers:
- **Core (Domain):** Contains Entities, and Business Logic.
- **Application:** Contains Interfaces, DTOs, Enums, and Application logic.
- **Infrastructure:** Handles data access (EF Core), SQL Server integration, and external services.
- **API:** The entry point (Web API) containing Controllers and Configurations.

---

## 🛠 Tech Stack
- **Backend:** .NET 8 (ASP.NET Core Web API)
- **Database:** SQL Server
- **ORM:** Entity Framework Core
- **Patterns:** Repository Pattern, Generic Repository, Specification Pattern.
- **Architecture:** Clean Architecture (Onion Architecture).
- **Tools:** Swagger UI for API testing.
